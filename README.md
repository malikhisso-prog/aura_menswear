# AURA - Old Money Elegance

موقع ويب متكامل (E-commerce Website) لعلامة أزياء رجالية كلاسيكية (Old Money Style).

## 🚀 المميزات (Features)
- تصميم فخم (Dark Mode) بألوان (أسود، رمادي، ذهبي، ولمسات بوردو).
- تصميم متجاوب بالكامل (Responsive) يعمل على الموبايل والتابلت والكمبيوتر.
- صفحة رئيسية احترافية مع عرض المنتجات المميزة.
- صفحة متجر مع إمكانية الفلترة حسب التصنيف.
- صفحة تفاصيل المنتج مع اختيار الكمية.
- سلة تسوق تفاعلية (إضافة، تعديل، حذف) بدون إعادة تحميل الصفحة (AJAX).
- صفحات قانونية (سياسة الخصوصية، الشروط والأحكام) وصفحة خطأ 404 أنيقة.

## 💻 التقنيات المستخدمة (Tech Stack)
- **Backend:** PHP 8+
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Data:** JSON (للتجربة)
- **Fonts:** Playfair Display & Cairo
- **Icons:** Font Awesome

## ⚙️ كيفية التشغيل (How to Run)
1. قم بتثبيت XAMPP.
2. ضع ملفات المشروع في مجلد `htdocs`.
3. شغل Apache من لوحة تحكم XAMPP.
4. افتح المتصفح على الرابط: `http://localhost/aura-website/`
